# Portfolio Tri Andika Gilang Permana

Website portfolio statis untuk VS Code.

## Struktur

- index.html
- style.css
- script.js

## Cara menjalankan

1. Buka folder project di VS Code.
2. Buka `index.html`.
3. Klik kanan -> **Open with Live Server** jika extension Live Server sudah terpasang.
4. Atau buka `index.html` langsung menggunakan browser.

## Data yang perlu diganti

Cari tulisan `[Belum diisi]` di `index.html`, lalu lengkapi:
- Nama kampus
- Periode pendidikan
- Periode magang
- Detail tugas magang
- Email
- WhatsApp
- LinkedIn
- GitHub
- Hasil masing-masing project

## Menambahkan foto project

Saat siap menambahkan foto, buat folder `images`, lalu masukkan gambar project dan tambahkan elemen `<img>` pada card project.
